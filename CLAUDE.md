# Rules for Claude in this repo
Owner: Scott (GitHub: scottachs). Hosted on GitHub Pages.

## How to talk to me
- Answer first. Short sentences. Say who does what.
- Correct me if I am wrong, and suggest a better way.
- I learn visually. Use before/after examples and numbered steps.
- No emojis.

## How to change files
- Change only what I ask. List every change you made.
- Keep each site a single self-contained index.html unless I say otherwise.
- Never commit API keys or secrets. Secrets live in Cloudflare.
- Google Analytics: Not decided yet. Do not add, remove, or change Analytics until Scott says.
- Designs must look human-made. No generic AI styling.
- Pages must work on iPhone Safari.

## This repo
- Plain everyday words. No critic vocabulary. Paraphrase lyrics, never quote. Keep the forced submit_analysis tool. The backend is a Cloudflare worker.
